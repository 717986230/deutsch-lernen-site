# Vue 旧站一致性基准

## 目的

Vue 是唯一继续演进的用户端；`src.html` 是它的视觉、交互与文案基准。迁移的目标是
保留旧站学习体验与数据连续性，而不是换一套产品设计。

## 基准与边界

- 只编辑 `web/src/` 和共享 `data/`；不手改部署产物。
- 旧站保留为回退实现，不向其中新增功能。
- 新功能先在 Vue 完成；若旧站没有对应页面，保持既有的颜色令牌、卡片层级和底部导航节奏。
- 不改变现有本地存储键和同步语义，避免老用户的学习进度断裂。

## 逐页对照

| 旧站区块 | Vue 路由 | 验收重点 |
|---|---|---|
| 首页 | `/home` | Hero、学习进度、功能卡和分级入口 |
| 词句大全 | `/phrases` | 搜索、等级与分类筛选、翻面、朗读、掌握标记 |
| 短文 / 餐厅 | `/reading` | 顶部切换、逐句朗读、词义小注与分级列表 |
| 连载 | `/series` | 连续阅读、语速和全篇朗读 |
| 情景对话 | `/dialog` | 场景列表、角色对话、逐句朗读与练习入口 |
| 拼写 / 测验 | `/spell`、`/quiz` | 旧站题型、进度键与反馈节奏 |
| 语法 / 发音 / 数字 | `/ref/:topic` | 信息层级、表格、示例、练习链接与双语数据 |
| 排行 / 我的 / 支持 | `/rank`、`/me`、`/support` | 旧站卡片层级、账号和同步行为 |

## 全局不可偏离项

- 顶栏使用旧站的次级入口顺序：拼写、测验、语法、发音、数字、排行、支持。
- 顶栏保留独立的德语、英语与主题按钮；图解词典从首页进入，不占用旧站顶栏位置。
- 底栏固定为首页、语句、短文、我的四项。
- 颜色、深浅主题、卡片圆角、间距、中文文案和移动端触摸目标沿用旧站；无障碍对比度可以高于旧站，不得降低。

## 每次改动的验收

1. 在 390px 宽度下核对目标页与旧站的信息层级、导航、首屏和交互入口。
2. 验证深浅主题、德英切换、返回导航和本地进度键。
3. 执行 `npm run build`；确认生成的 PWA 外壳与数据文件完整。
4. 只在完成核心学习流程的浏览器回归后，才进入发布评审。
